衍生品情绪
Funding资金费率；正值多头付费，负值空头付费。
OI未平仓合约量；上升通常表示新杠杆资金进场。
大户多空大户账户多空比，偏离过大代表拥挤风险。
主动买卖Taker 买卖比；高于均值偏多，低于均值偏空。
拥挤度组合Funding+基差+OI 同向偏热时，提示多/空拥挤。
盘口与波动
盘口失衡近价区买卖挂单厚度差，衡量承接/抛压。
盘口集中度基于 depth 挂单金额计算，不是 Binance 原生字段。
RSI价格强弱指标；高位偏热，低位偏冷。
ATR波动幅度指标；越大代表波动越剧烈。
Bollinger布林带位置；靠上轨偏热，靠下轨偏冷。
VWAP成交量加权均价；偏离过大常有回归压力。
趋势与结论
MACD动能方向与变化；柱体正负与收敛/发散看动能。
ADX趋势强度指标；常见阈值：>25 强趋势，<20 偏震荡。
趋势结构基于均线关系判断 up/down/side。
评级A/B/CA信号更一致，B中等，C分歧较大。
跨所共振Binance/Bybit/OKX 的方向一致性与价差离散度。
说明：APP里的部分“资金流向分档”属于私有统计口径，公开 API 不可完全复刻。
